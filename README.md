# Cyber Glitch: Ver. 2.0

A **cyberpunk browser game** built with **React + TypeScript + Vite**.

Cyber Glitch is a fast-paced platformer project with a neon sci-fi aesthetic, multiple handcrafted levels, and gameplay elements designed to feel flashy, chaotic, and fun. The project focuses on creating a distinctive visual identity while still being lightweight enough to run as a modern web game.

## Project highlights

- cyberpunk visual style
- 5 handcrafted levels
- dynamic particle effects
- screen shake and impact feedback
- themed UI and game-state flow
- browser-friendly frontend setup with Vite

## Tech stack

- React
- TypeScript
- Vite
- Lucide React

## Why I built it

This project explores the intersection of:

- game feel
- visual design
- frontend engineering
- interactive level-based experiences

It is both a coding project and a presentation project: part game prototype, part aesthetic experiment.
